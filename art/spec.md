# 遥远之地 美术规格（方向「晴空奇境」）

开工拍板：美术方向「晴空奇境」（`decisions/kickoff.json`），样张见 `assets/kickoff-1-qingkong.png`。
叫法：奇石 / 灵兽 / 蓟草；菌林（红）、溪谷（绿）、石原（蓝）、岩城（黄）。

## 1. 风格

- **基调**：明亮饱和的 16 位奇幻冒险绘本风，侧视的小风景，深色描边，蓬松白云。白天是晴空，夜晚是深紫星空配弯月，两者反差要大。
- **光照**：白天的光从左上方来，暖色高光；夜晚是冷色月光，从上方来，偶尔有暖色小光点（萤火、窗光）。
- **描边**：主体用深褐近黑描边（`#2b1d14`），远景不描边。
- **像素密度**：卡面底图 128×128 原生，界面上按整数倍显示，1 个原图像素 = 1 或 2 个屏幕像素，不做非整数缩放。所有图都由 PixelLab 原生出到目标尺寸，不拿大图缩小。缩略图（`*-sm`）是例外，由代码从原图缩一半生成。
- **调色板**（主色 HEX，界面卡框、色条、按钮也用这一套）：

| 用途 | HEX |
|---|---|
| 描边 / 深色字 | `#2b1d14` |
| 卡框奶油色 | `#f4e4c1` |
| 徽章底（亮） | `#fffaec` |
| 菌林 红 | `#c4342c` |
| 溪谷 绿 | `#4aa046` |
| 石原 蓝 | `#3e70c4` |
| 岩城 黄 | `#e2b230` |
| 无色圣所 灰 | `#8a8480` |
| 白天天空 | `#6cc4f0` |
| 夜空紫 | `#3c226e` |
| 月亮 | `#faecaa` |
| 太阳 | `#ffc828` |
| 牌桌木色（夜） | `#5c3a24` |

## 2. 界面叠加约定（重要）

**图上没有任何文字和数字**。以下内容全部由界面用代码画在底图上面：

- 区域卡：卡框（奶油色 4px + 深色 1px 描边）；左上角编号圆（像素字体数字），右边紧挨着昼/夜徽章（`icon/day.png` / `icon/night.png`）；右上角奇观徽章（0–2 个，`icon/stone|chimera|thistle.png`）；线索徽章（`icon/clue.png`）跟在编号后面；底部地形色条（`swatch/<色>.png` 平铺，带花纹，色盲也分得清）；居民头像（`resident/*.png`）放在底图左下角；前置条件框和任务框（图标 + 分数数字）在底图右下角，用代码画圆角框。
- 圣所卡：同样的卡框，颜色用地形色或灰色；左上放夜（月亮）/线索徽章，右上放奇观，底部是任务框（代码）。
- 四色套图标：代码用 4 个 `swatch` 拼 2×2（`icon/colorset.png` 已按这个做法导出一张）。
- 分数、编号、任务数值、玩家名都用像素字体由代码绘制。

卡面底图的左上角、右上角和左下角会被徽章和头像盖住，所以挑图时主体偏中、偏上为好。

## 3. 素材清单

路径都是将来的 `apps/web/public/art/` 下的路径，定稿在暂存目录 `art/out/final/` 下，目录结构相同。
「倍数」指原图像素到屏幕 CSS 像素的整数倍；昼/夜指界面的白天版、夜间版主题（不是卡上的昼夜）。

### 3.1 区域卡

| 文件 | 原始尺寸 | 显示倍数 | 透明 | 帧 | 主题 | 用途 / 界面 |
|---|---|---|---|---|---|---|
| `region/<biome>-<day\|night>-<1..3>.png`（biome = red/green/blue/yellow，共 24 张） | 128×128 | ×1（出牌区、手牌）、×2（点开看大图） | 否 | 1 | 两套主题共用 | 区域卡底图。卡号按 `(id % 3) + 1` 选变体，同一地形同昼夜相邻不重样 |
| `region-sm/<同上>.png`（24 张，代码生成） | 64×64 | ×1 | 否 | 1 | 共用 | 手机和别人出牌区的缩略卡 |
| `back/region.png` | 128×128 | ×1 / ×2 | 否 | 1 | 共用 | 区域卡背（终局倒序翻牌、牌堆、公共牌未翻开） |
| `back/region-sm.png`（代码生成） | 64×64 | ×1 | 否 | 1 | 共用 | 缩略卡背 |

卡号 → 地形和昼夜见规则书 §2.3（夜晚卡用 `-night-` 变体）。

## 4. 卡号 → 图的映射（给开发）

- 区域卡：`region/${color}-${night ? 'night' : 'day'}-${(id % 3) + 1}.png`
- 居民：有任务的卡 `resident/${color}-${(id % 4) + 1}.png`
- 圣所卡：有颜色 → `sanctuary/${color}.png`；无色带夜 → `gray-night.png`；其他无色 → `gray-day-${(n % 2) + 1}.png`（n 为 S 编号）
